// 01 · introducción

¿Qué es YourIA?

YourIA es una inteligencia artificial desarrollada dentro de MERTEK, enfocada en asistir en tareas técnicas y de programación. Su propósito es funcionar como un copiloto de desarrollo: ayudar a escribir código, entender fragmentos existentes, depurar errores y automatizar flujos repetitivos.

No es un chatbot genérico. Está entrenada y orientada a resolver problemas concretos del día a día técnico: sintaxis, refactorización, documentación, generación de scripts y explicación de lógica.

Estado actual: versión en desarrollo (v0.1). Algunas capacidades listadas ya funcionan, otras están en camino. Consulta el roadmap.
// 02 · capacidades

¿Qué puede hacer?

Estas son las áreas donde YourIA está pensada para aportar valor real:

  • Generación de código en múltiples lenguajes a partir de una descripción en lenguaje natural.
  • Explicación de código existente, línea por línea o a nivel de bloque.
  • Depuración asistida: detección de errores comunes y sugerencias de corrección.
  • Refactorización para mejorar legibilidad, eficiencia o estructura.
  • Automatización de tareas repetitivas de desarrollo (scripts, tests, formateo).
  • Generación de documentación técnica a partir de código fuente.

Áreas de especialización

Código

Python, JavaScript, HTML/CSS, C++ y otros lenguajes comunes.

Debug

Análisis de errores, stack traces y sugerencias de fix.

Automatización

Scripts, tareas repetitivas y flujos de trabajo.

Documentación

Docs técnicas, comentarios y explicaciones claras.

// 03 · uso

Cómo se usa

YourIA se invoca mediante prompts en lenguaje natural. No necesitas aprender una sintaxis especial: describe lo que quieres y la IA interpreta la tarea.

Ejemplo 1 · Generar una función

// Prompt: Genera una función en Python que reciba una lista de números y devuelva la mediana sin usar numpy.

Ejemplo 2 · Explicar código

// Prompt: Explícame qué hace este fragmento paso a paso: def f(x): return x if x < 2 else f(x-1) + f(x-2)

Ejemplo 3 · Depurar error

// Prompt: Este código lanza "TypeError: unsupported operand type(s)". ¿Por qué y cómo lo arreglo? total = "10" + 5
Consejo: cuanto más contexto das (lenguaje, versión, restricciones), más precisa es la respuesta. Evita prompts ambiguos.

// 06 · faq

Preguntas frecuentes

¿YourIA es gratis?

Aún no hay un modelo de acceso definido. La prioridad actual es completar el motor técnico antes de abrir un plan público.

¿En qué se diferencia de otros asistentes de código?

YourIA nace dentro del ecosistema MERTEK y está pensada para integrarse con sus proyectos internos. El enfoque es técnico y directo: resolver, no conversar.

¿Qué lenguajes soporta?

Actualmente se está trabajando con lenguajes comunes (Python, JavaScript, HTML/CSS, C++). La lista puede ampliarse según las necesidades del ecosistema.

¿Puedo colaborar en el desarrollo?

Sí. MERTEK recluta talento con experiencia en programación, robótica o tecnología. Puedes contactar a través del sitio principal.

¿Está disponible la descarga?

Todavía no. La Fase 2 (motor técnico) debe completarse antes de publicar una versión usable.
